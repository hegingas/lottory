# 漏斗参数回测验证

对 5 个彩种全量历史数据回测，验证每个漏斗层的参数是否有效，输出最优阈值建议。

## 执行

```bash
# 全量回测（5个彩种，约8分钟）
python scripts/backtest_all.py

# 双色球单彩种回测（300期滚动窗口，多方案对比）
python scripts/backtest_funnel.py
```

## 回测内容

| 验证层 | 测试内容 | 输出 |
|--------|----------|------|
| 🔪 深冻排除 | 6 档阈值(0.80-0.99)误杀率 | 最优阈值 + 可用性判定 |
| 🔥 热/冷分类 | 6 组阈值命中率 + 区分度 | 最优热/冷参数 |
| 🏗️ 结构约束 | 奇偶/大小 Top 覆盖 + 和值 1σ | 覆盖率 + 分布 |
| 🔍 连号/重号 | 200 期分布统计 | 概率 + 分布明细 |
| 📐 KL8 专属 | 十码段分布 | 每段均数 |

## 参数配置

回测结果验证的参数集中在 `config/funnel_params.json`，修改后重跑回测即可验证。

## 输出

- 每个彩种的结构统计和参数建议
- 深冻排除：建议阈值 + 误杀率 → 可用/不可用判定
- 热/冷分类：区分度 → 可用/几乎无用判定
- 最终建议：哪些漏斗层有统计支撑
