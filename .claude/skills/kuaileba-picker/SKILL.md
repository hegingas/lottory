# 快乐八选号（五层漏斗 · 逐层过滤）

## 项目依赖限制

- **仅允许**读取 `data/processed/kl8_draws.csv`
- **禁止**使用 src/、scripts/、history/、config 等任何其他项目内容

## 原则

- 彩票为随机游戏，历史统计**不能**保证未来结果
- 输出**选十单式10码**（升序）
- 时间戳：北京时间 ISO-8601（`+08:00`）

---

## 架构：五层漏斗选号

```
选快乐八 Skill 触发
    │
    └─→ Workflow 脚本 (scripts/workflow.js)
           │
           ├─ Phase 1: 数据准备 (haiku)
           └─ Phase 2: 五层漏斗 (单Agent)
                 ├─ 🔪 杀号   80→~50
                 ├─ 📈 趋势   ~50→~35
                 ├─ 🏗️ 结构   ~35→~25
                 ├─ 🔍 形态   ~25→~18
                 └─ 🎯 精选   最终选十10码
```

### 与双色球的差异

| 差异点 | 快乐八 |
|--------|--------|
| 号码池 | 01-80，每期开20个，自选10个 |
| 大小分界 | 01-40小，41-80大 |
| 十码段 | 8段：01-10/11-20/.../71-80 |
| 连号/重号 | **无约束**（开20个号连号重号太常见） |
| 结构重点 | 奇偶比+大小比+十码段覆盖+和值 |
| 无后区 | 纯单区选号 |

---

## 选号约束

- 选十10码，升序排列
- 十码段分布尽量均衡（8段覆盖≥5段）
- 奇偶比不过于极端
