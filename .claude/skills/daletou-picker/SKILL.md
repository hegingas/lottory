# 大乐透选号（分析 → 预测 → 组号 三位一体）

## 原则

- 彩票为随机游戏，历史统计**不能**保证未来结果。输出必须声明：娱乐目的、概率本质、过往统计仅供参考。
- **去核心化约束（强制）**：禁止直接围绕最新窗口 Top 热号骨架拼注，必须加入反集中约束（分区均衡、过热惩罚、热温冷混合），在正文写明"已执行去核心化约束"。
- **防重合约束（强制）**：任一预测单式不得与历史任一期完全重合；与最新一期重合号数 ≤3（全号码位 7 码计算）。若不满足，替换低分重合号后再输出。
- **时间戳规则（强制）**：`最后更新`、`预测生成时间` 使用北京时间 ISO-8601（`+08:00`）。

## 数据来源

1. `data/processed/dlt_draws.csv`（优先）
2. 否则回退 `data/raw/` 或用户指定路径，并在输出中写明数据来源层级

## 执行流程（三步走，不可跳步）

### 第一步：历史分析

基于 `data/processed/dlt_draws.csv`，默认近 **30** 期（`DEFAULT_STATS_WINDOW`），输出：

- **频次统计**：前区（01–35）和后区（01–12）各号码出现次数排名
- **冷热分级**：热号（Top 前区 8 / 后区 3）、温号、冷号（Bottom 前区 8 / 后区 3）
- **遗漏分析**：当前遗漏期数、最大历史遗漏、是否处于冷态
- **结构分析**：奇偶比、大小比（前区 01–17 为小，18–35 为大）、和值区间、AC 值、连号个数、质合比
- **多窗口对照**（可选）：30/100/300 期间一指标对比表，仅作稳定性描述

完成后**必须**更新 `history/daletou_analysis.md`。

### 第二步：号码预测

**规则口径**：

- **区间掩码马尔可夫**（定候选球域）：前区 7 段（每段 5 个连续号：01–05 / 06–10 / 11–15 / 16–20 / 21–25 / 26–30 / 31–35），后区 4 段（01–03 / 04–06 / 07–09 / 10–12）。计算每段「是否至少出 1 球」的二进制掩码，全历史做相邻期一阶马尔可夫 + 拉普拉斯平滑，取末态条件下概率最大的下一掩码，扩展至可凑满所需球数。**仅在掩码并集内**做后续选号。
- **多因子加权**（在候选域内打分）：min-max 归一后按 8 项独立因子加权：

| 因子 | 权重 |
|---|---|
| 马尔可夫转移（一阶+二阶混合，40%/60%） | 25% |
| 当前遗漏 | 18% |
| 频次（窗口内出现次数） | 14% |
| 区间热度 | 12% |
| 近 K 期密度 | 10% |
| 奇偶对齐 | 8% |
| 大小/半区对齐 | 8% |
| 和值带对齐 | 5% |

- **分区上限**：前区每 5 码一小区至多 **2** 个；后区每 3 码一小区至多 **2** 个。
- **自动择优**（可选）：`use_mask=False` 跳过掩码约束，全号池开放；`--auto-strategy` 自动选取更优策略。

**区间选择说明（强制）**：必须解释：上期各区命中掩码（人类可读）→ 条件最大概率下一掩码（含平滑概率值）→ 历史转移总次数 → 展开后最终使用的掩码 → 边缘情况说明。

**强制输出**：

- **5 注单式**（每注前区 5 + 后区 2）
- 每注逐号选择原因 + 预测生成时间（北京时间 ISO-8601）
- **1 注单式优选**：分数最高的单式，含总分、关键因子贡献
- 标注"防重合约束已执行（历史不全重合 + 最新期≤3）"

完成后**必须**更新 `history/daletou_prediction.md`。

### 第三步：投注组号

基于预测结果，在 **10～30 元（含）** 金额带内构造投注方案：

- 覆盖单式、复式、胆拖的注数与金额计算
- 用户声明不要倍投时，仅用多注单式/复式/胆拖凑额，不得用倍数投注
- 前区复式注数 = C(n,5)，后区复式注数 = C(m,2)，总注数 = 前区注数 × 后区注数
- 输出注数金额明细表

## 职责隔离

本 Skill 仅服务大乐透选号。**禁止**：其他彩种预测（分别用「选双色球」「选快乐八」「选排列5」「选七星彩」）、数据采集落盘（用 `lottery-draw-sync` / `lottery-draw-dlt-ssq`）、全流程编排（用 `lottery-manager`）。

## 禁止

- 不得输出「稳赚」「必中」「投资回报率」等误导表述
- 不得输出「建议投入金额占收入比例」类财务建议
- 不得伪造「模型回测收益率」
- 不得在未经用户要求下创建或修改脚本文件
