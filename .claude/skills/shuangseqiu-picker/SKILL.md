# 双色球选号（五人委员会 · 实时辩论 · 一注定乾坤）

## 项目依赖限制（硬性）

- **仅允许**读取项目下的彩票历史数据文件：`data/processed/ssq_draws.csv`
- **禁止**使用、引用、导入本项目下任何其他内容（src/、scripts/、history/、config等）
- 所有分析逻辑由各 Agent 自行实现

## 原则

- 彩票为随机游戏，历史统计**不能**保证未来结果。
- **只出一注**，不撒网。
- **时间戳**：北京时间 ISO-8601（`+08:00`）。

---

## 选号委员会 · 五人团队

### 角色定义

| 角色 | 视角 | 分析重点 |
|---|---|---|
| **趋势猎手** | 四窗口频率趋势 | f1/f2/f3/f4 上升势头，追 📈 |
| **遗漏判官** | 当前遗漏 + 历史极值 | 超跌冷号回补，捞 📉中的反弹候选 |
| **结构大师** | 奇偶/大小/和值/AC | 保证最终组合结构不跑偏，符合历史分布 |
| **形态侦探** | 连号/重号/区间分布 | 保证组合"看起来像会开的"，形态合理 |
| **博弈鬼才** | 反共识 | 主动避开过热号、大众心理号，专挑被忽视的角落 |

### 讨论规则

- 每轮每人必须**明确提名**一注完整号码（红6+蓝1）+ 简短理由
- 辩论时每人须**点评至少一位其他委员**的提名（指出同意/反对的具体号码和理由）
- 禁止"我觉得"式主观发言，必须引用数据（频率/遗漏/趋势等）
- 首席不参与提名，只裁定

## 执行流程（Workflow）

### Phase 1：数据准备

读取 `data/processed/ssq_draws.csv`，提取：
- 全历史期号范围
- 最新一期开奖号码（上期基准）
- 近 50 期完整数据（供各 Agent 独立分析）

### Phase 2：并行独立分析（Spawn 5 Agent）

使用 `Agent` 工具**同时** spawn 5 个子 Agent，每个获得相同的数据上下文 + 专属角色指令：

```
Agent 1 — 趋势猎手：
  对红球01-33和蓝球01-16的每一个号码，计算近10/20/30/50期四个窗口的出现频率，
  判定📈上升/➡️平稳/📉下降趋势。基于趋势配额（红：升3+平2+降1，蓝：升或平取最高）
  提名一注。输出：红6+蓝1 + 每个号的趋势标签和得分 + 理由。

Agent 2 — 遗漏判官：
  对每个号码计算当前遗漏期数、历史最大遗漏、遗漏分位数。
  重点关注当前遗漏超过历史50%分位的号码，在其中挑趋势企稳的。
  提名一注。输出同上格式。

Agent 3 — 结构大师：
  先统计近50期的奇偶比、大小比(01-16小/17-33大)、和值、AC值分布，
  确定"最合理结构区间"。在此结构约束下选号。
  提名一注。输出：结构约束 + 号码 + 理由。

Agent 4 — 形态侦探：
  统计近50期的连号频率、重号(与各自上期)频率、区间覆盖模式。
  强制要求：至少一组连号 + 与上期重叠1-2号。
  在此形态约束下选号。提名一注。

Agent 5 — 博弈鬼才：
  先标记"过热号"(近10期出现≥4次)和"大众号"(近30期出现≥8次)，
  主动回避这些号。在剩余池中按趋势得分选号。
  提名一注。
```

每个 Agent 完成后通过 `SendMessage` 将提名发送给 main。

### Phase 3：圆桌辩论（1 轮）

Main 收集全部 5 人提名后，将其他人的提名打包发给每个 Agent，要求：

```
你收到了其他委员的提名方案。请：
1. 选一位委员的方案，点评你同意其哪些号码选择（至少2个）、反对哪些（至少1个），引用数据说明
2. 辩护你自己的方案：针对可能被攻击的弱点，用数据回应
3. 回复到 main
```

### Phase 4：首席裁定

Main（首席裁判）收到所有辩论回复后：

1. 汇总 5 人提名 + 辩论要点
2. 按以下权重裁定最终一注：
   - 趋势猎手 25%
   - 遗漏判官 20%
   - 结构大师 20%
   - 形态侦探 20%
   - 博弈鬼才 15%
3. 最终号码必须满足：连号✅ + 上期重叠1-2✅
4. 若裁定号码与某位委员一致，说明"采纳 XX 的方案"
5. 若裁定号码为混合方案，说明"前区采纳 A 的 XX、B 的 YY，蓝球采纳 C 的 ZZ"
