# 快乐八选号（分析 → 预测 → 组号 三位一体）

## 项目依赖限制（硬性）

- **仅允许**读取项目下的彩票历史数据文件：`data/processed/kl8_draws.csv`、`data/raw/` 下的原始抓取存档
- **禁止**使用、引用、导入、执行本项目下任何其他内容，包括但不限于：`src/` 下的 Python 模块、`scripts/` 下的脚本、`src/lottery/config.py` 中的配置常量、`history/` 下的既有分析/预测归档
- 所有统计分析、马尔可夫建模、多因子评分、分区约束、组号计算等逻辑**必须由本 Skill 自行实现**，不得调用项目现有代码
- 本约束的目的是确保 Skill 独立可迁移，不绑定本项目代码库

## 原则

- 彩票为随机游戏，历史统计**不能**保证未来结果。输出必须声明：娱乐目的、概率本质、过往统计仅供参考。
- **去核心化约束（强制）**：禁止直接围绕最新窗口 Top 热号骨架拼注，必须加入反集中约束（分区均衡、过热惩罚、热温冷混合），在正文写明"已执行去核心化约束"。
- **重合上限（强制）**：预测"选十参考 11 码"与最新一期真实开奖 20 码的重合数 ≤ **4**。超出时按分数从低到高替换重合号。
- **时间戳规则（强制）**：`最后更新`、`预测生成时间` 使用北京时间 ISO-8601（`+08:00`）。

## 玩法约束

- **仅选十**，复式仅允许 **11 码选十复式**（C(11,10) = 11 注 = 22 元）
- 开奖 20 码 vs 自选 10 码中奖逻辑不同，须写清区分

## 数据来源

1. `data/processed/kl8_draws.csv`（优先）
2. 否则回退 `data/raw/` 或用户指定路径，并在输出中写明数据来源层级

## 执行流程（三步走，不可跳步）

### 第一步：历史分析

基于 `data/processed/kl8_draws.csv`，默认近 **30** 期（`DEFAULT_STATS_WINDOW`），输出：

- **频次统计**：01–80 各号码在窗口内出现次数排名
- **冷热分级**：热号（Top 20）、温号（中间 40）、冷号（Bottom 20）
- **遗漏分析**：当前遗漏期数、最大历史遗漏
- **结构分析**：奇偶比、大小比（01–40 小 / 41–80 大）、和值分布、十码段覆盖率
- **多窗口对照**（可选）：30/100/300 期间一指标对比表，仅作稳定性描述

完成后**必须**更新 `history/kuaileba_analysis.md`。

### 第二步：号码预测

**规则口径**：

- **十码段掩码马尔可夫**（单一路径，定候选球域）：8 个十码段（01–10 / 11–20 / … / 71–80），计算每段「是否至少出 1 球」的二进制掩码，全历史做相邻期一阶马尔可夫 + 拉普拉斯平滑，取末态条件下概率最大的下一掩码。经 `expand_kl8_decadic_mask` 保证至少 **4** 个活跃段，每段 **1～5** 个号可凑满所需球数。**仅在展开后的活跃段并集内**做后续选号。
- **多因子选号**（在候选域内打分）：min-max 归一后按加权取满 20 码，同分随机。
- **选十 11 码**：优先在 20 码中无放回随机并校验十码段约束，失败则按回退规则补齐。

**区间选择说明（强制）**：必须解释：上期十码段命中掩码 → 条件最大概率下一掩码（含平滑概率值）→ 历史转移总次数 → expand 后的活跃段 → 边缘情况说明。

**强制输出**：

- **参考开奖 20 码**（升序，01–80）
- **选十参考 11 码**（升序），标注"重合约束已执行（≤4）"
- **1 组最优 11 码**：分数最高的组合，含总分、关键因子贡献、生成时间

完成后**必须**更新 `history/kuaileba_prediction.md`。

### 第三步：投注组号

在 **10～30 元（含）** 金额带内构造投注方案：

- **默认方案**：11 码选十复式 = C(11,10) = 11 注 = **22 元**（推荐）
- **省钱方案**：搭配 5 注选十单式 = **10 元**
- **满额方案**：11 码复式 + 4 注单式 = 26 元
- 不得默认加入其他复式档位
