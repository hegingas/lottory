# 排列5选号（五层漏斗 · 按位过滤）

## 项目依赖限制

- **仅允许**读取 `data/processed/pl5_draws.csv`
- **禁止**使用 src/、scripts/、history/、config 等任何其他项目内容

## 原则

- 彩票为随机游戏，历史统计**不能**保证未来结果
- 输出**一注5位数字**（每位0-9，允许重复）
- 时间戳：北京时间 ISO-8601（`+08:00`）

---

## 架构：五层漏斗（按位独立）

```
选排列5 Skill 触发
    │
    └─→ Workflow 脚本 (scripts/workflow.js)
           │
           ├─ Phase 1: 数据准备 (haiku) — 按位统计d1-d5
           └─ Phase 2: 五层漏斗 (单Agent)
                 ├─ 🔪 杀号   每位10→~6个候选数字
                 ├─ 📈 趋势   每位~6→~4个
                 ├─ 🏗️ 结构   按位奇偶/大小约束
                 ├─ 🔍 形态   跨位模式（重复/顺子/对称）
                 └─ 🎯 精选   最终5位数字
```

### 排列5特点

| 特点 | 说明 |
|------|------|
| 按位独立 | d1只跟历史d1比，d2只跟d2比...每位独立分析 |
| 允许重复 | 同数字可以出现在多个位置，按位分析不互相排除 |
| 大小分界 | 0-4小，5-9大 |
| 无连号约束 | 排列5没有连号/重号硬约束 |
| 跨位形态 | 关注全5位是否有2位以上重复、是否有顺子(如12345)、对称模式 |

---

## 选号约束

- 每位独立筛选，按位输出
- 允许数字跨位重复
- 全5位奇偶比不过于极端（不出现全奇或全偶）
