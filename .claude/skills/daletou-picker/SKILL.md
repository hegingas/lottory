# 大乐透选号（五层漏斗 · 逐层过滤）

## 项目依赖限制

- **仅允许**读取 `data/processed/dlt_draws.csv`
- **禁止**使用 src/、scripts/、history/、config 等任何其他项目内容

## 原则

- 彩票为随机游戏，历史统计**不能**保证未来结果
- 默认输出**一注复式**（前区10-12码+后区3-4码）或**3注单式**
- 时间戳：北京时间 ISO-8601（`+08:00`）

---

## 架构：五层漏斗选号

```
选大乐透 Skill 触发
    │
    └─→ Workflow 脚本 (scripts/workflow.js)
           │
           ├─ Phase 1: 数据准备 (haiku)
           └─ Phase 2: 五层漏斗 (单Agent)
                 ├─ 🔪 杀号   前35→~22, 后12→~8
                 ├─ 📈 趋势   ~22→~15, ~8→~6
                 ├─ 🏗️ 结构   ~15→~11, ~6→~5
                 ├─ 🔍 形态   ~11→~8, ~5→~4
                 └─ 🎯 精选   1注复式或3注单式
```

| 后区约束 | 后区与上期重叠不超过1个 |

---

## 选号约束

- **至少满足一个**：前区连号 或 与上期重叠1-2个
- **后区上限**：后区与上期重叠不超过1个
- **去重**：不与历史任一期前区完全重合
