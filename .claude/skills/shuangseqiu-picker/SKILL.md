## 核心算法：走势跟随（与大乐透同构）

### 多窗口频率曲线

红球 01–33 和蓝球 01–16 的**每一个号码**，计算四个窗口的出现频率：

| 窗口 | 期数 | 用途 |
|---|---|---|
| W1 | 近 10 期 | 短期热度 |
| W2 | 近 20 期 | 中短期趋势 |
| W3 | 近 30 期 | 中期基准 |
| W4 | 近 50 期 | 长期均值 |

频率 = 窗口内出现次数 / 窗口期数。

### 趋势三分类

| 趋势 | 判定条件 | 含义 |
|---|---|---|
| 📈 **上升** | f1 > f2 且 f2 ≥ f3，或 f1 比 f4 高 30%+ | 势头在爬升 |
| 📉 **下降** | f1 < f2 且 f2 ≤ f3，或 f1 比 f4 低 30%+ | 热度退潮 |
| ➡️ **平稳** | 不满足上升或下降 | 稳定波动 |

### 趋势得分

同类内排序用：

```
得分 = f1×0.4 + f2×0.3 + f3×0.2 + f4×0.1
```

## 选号流程

### 红球（选 6 个号，01–33）

**配额**：📈上升×3 + ➡️平稳×2 + 📉下降×1

**步骤**：

1. 全 33 个号按趋势分类，同类内按得分降序
2. 上升池取 Top 3、平稳池取 Top 2、下降池取 Top 1 → 初步 6 码
3. **连号约束**：6 码中无连号 → 将得分最低的一位替换为其相邻号（优先仍在候选池内的），直到出现至少一组连续号
4. **上期重叠约束**：检查与上期红球的重合数：
   - 重合 0 个 → 得分最低者替换为上期红球中得分最高者
   - 重合 > 2 个 → 多余的上期号中得分最低者替换为同类池下一候选
   - 最终保证 **1 或 2 个**重合
5. **去重**：不与历史任一期红球完全重合；若撞车则随机替换一码
6. 升序排列

### 蓝球（选 1 个号，01–16）

**配额**：📈上升 或 ➡️平稳（取两者中得分最高的那个）

**步骤**：

1. 上升池 + 平稳池分别取 Top 1，比较得分，取更高者
2. 若与上期蓝球相同，改用另一池的 Top 1
3. 若仍相同，取得分次高者

## 执行流程

### 第一步：历史分析

读 CSV，默认取近 **50** 期，输出：

- **走势面板**：红球+蓝球每个号码的四窗口频率 + 趋势标签
- **趋势分布**：红球/蓝球上升/平稳/下降各多少个
- **上期回顾**：上期开奖各号趋势标签
- **结构快照**：近 30 期奇偶比、大小比（红球 01–16 小/17–33 大）、和值均值、连号频率

完成后更新 `history/shuangseqiu_analysis.md`。

### 第二步：号码预测

按「走势跟随」算法选出唯一一注，强制输出：

- **一注单式**：红球 6 码（升序）+ 蓝球 1 码
- 每个号的趋势标签（📈/➡️/📉）和得分
- 与上期重合数、连号位置
- 各号选号逻辑简述
- 预测生成时间（北京时间 ISO-8601）

完成后更新 `history/shuangseqiu_prediction.md`。

### 第三步：投注组号

一注 2 元。用户可要求追加复式/胆拖，默认只用这一注。
