# 双色球选号（五层漏斗 · 逐层过滤 · 一注定乾坤）

## 项目依赖限制

- **仅允许**读取 `data/processed/ssq_draws.csv`
- **禁止**使用 src/、scripts/、history/、config 等任何其他项目内容
- 所有分析逻辑在 Workflow 内完成

## 原则

- 彩票为随机游戏，历史统计**不能**保证未来结果
- 默认输出**一注复式**（红10-12码+蓝2-3码）或**3注单式**
- 时间戳：北京时间 ISO-8601（`+08:00`）

---

## 架构：五层漏斗选号

```
选双色球 Skill 触发
    │
    └─→ Workflow 脚本 (scripts/workflow.js)
           │
           ├─ Phase 1: 数据准备 (haiku)
           │     └─ 读取CSV，计算6大类统计指标
           │
           └─ Phase 2: 五层漏斗 (单Agent逐层过滤)
                 │
                 ├─ 🔪 第1层 杀号：硬规则排除30-40%
                 │    候选池 33→~20红, 16→~10蓝
                 │
                 ├─ 📈 第2层 趋势：打分排序取前60-70%
                 │    候选池 ~20→~14红, ~10→~7蓝
                 │
                 ├─ 🏗️ 第3层 结构：框架约束反推淘汰
                 │    候选池 ~14→~10红, ~7→~5蓝
                 │
                 ├─ 🔍 第4层 形态：连号/重号/同尾/区间
                 │    候选池 ~10→~8红, ~5→~4蓝
                 │
                 └─ 🎯 第5层 精选：定胆→出号→博弈微调→终检
                      输出：1注复式 或 3注单式
```

### 各层淘汰规则

| 层 | 核心逻辑 | 淘汰率 |
|----|----------|:---:|
| 杀号 | 连续重号过热、深度冷冻、百期死号、蓝球降温 | 30-40% |
| 趋势 | 四窗口（10/30/50/100期）频率+遗漏回补信号+趋势拐点 综合打分 | 20-30% |
| 结构 | 奇偶比+大小比+和值范围+012路+质数 框架约束 | 15-25% |
| 形态 | 连号预期+重号预期+同尾+区间覆盖+跨度+龙头凤尾 | 10-20% |
| 精选 | 胆码确认→组合出号→博弈微调→硬约束终检 | 最终输出 |

---

## 选号约束

- **至少满足一个**（历史概率 89.2%）：连号（至少一组连续号）**或** 上期重叠（与最新一期重叠 1-2 个号）
- **去重**：不与历史任一期完全重合
- **AC值**：6-10 合理范围
