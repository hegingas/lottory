# 彩票选号 · Dynamic Workflow

基于 Claude Code Workflow 的**大乐透、双色球、快乐八、排列5、七星彩**选号项目。每个彩种由多人委员会对抗验证 Workflow 驱动，独立提名 → 互审交锋 → 收敛裁定，输出一注推荐号码。

## 重要说明

彩票开奖具有随机性，仓库内任何统计、预测或组合方案**均不构成投资建议或中奖保证**，仅供学习与娱乐用途。

## 快速开始

在 Claude Code 中直接对话：

- **选大乐透** → 自动触发 `daletou-picker` Skill（五人委员会 Workflow）
- **选双色球** → `shuangseqiu-picker`（五人委员会 Workflow）
- **选快乐八** → `kuaileba-picker`（四人委员会 Workflow）
- **选排列5** → `pailie5-picker`（四人委员会按位 Workflow）
- **选七星彩** → `qixingcai-picker`（四人委员会按位 Workflow）

或使用 Skill 工具显式调用：

```
/daletou-picker
/shuangseqiu-picker
/kuaileba-picker
/pailie5-picker
/qixingcai-picker
```

## Workflow 架构

```
Skill 触发
  └─→ Workflow 脚本
        ├─ Phase 1: 数据准备（读取 CSV，提取统计上下文）
        ├─ Phase 2: 并行独立提名（4-5 个 Agent 各自分析选号）
        ├─ Phase 3: 对抗验证循环（最多 5 轮，互审 → 自证 → 收敛检查）
        │    ├─ 收敛（≥3 共识）→ 进入裁定
        │    └─ 未收敛 → 加权投票 + 最终陈述 → 强制裁定
        └─ Phase 4: 首席裁定（Opus，综合辩论记录输出最终一注）
```

## 委员会成员

| 委员 | 方法论 | 彩种覆盖 |
|------|--------|----------|
| 🏹 趋势猎手 | 四窗口频率曲线，判定号码趋势方向 | 全部 |
| ⚖️ 遗漏判官 | 盯遗漏和历史极值，超跌回补信号 | 全部 |
| 🏗️ 结构大师 | 奇偶/大小/和值框架，结构合理性至上 | 全部 |
| 🔍 形态侦探 | 连号/重号/区间形态，瑕疵零容忍 | 大乐透、双色球 |
| 🎲 博弈鬼才 | 反共识选号，回避过热号和大众心理号 | 全部 |

## 彩种规则

| 彩种 | 主区 | 副区 | 约束 |
|------|------|------|------|
| 大乐透 | 前区 5 枚，01–35 | 后区 2 枚，01–12 | 连号 + 上期重叠 1-2 |
| 双色球 | 红球 6 枚，01–33 | 蓝球 1 枚，01–16 | 连号 + 上期重叠 1-2 |
| 快乐八 | 选十 10 码，01–80 | — | 十码段均衡分布 |
| 排列5 | 5 位数字，0–9 | — | 按位独立，允许重复 |
| 七星彩 | 前区 6 位，0–9 | 后区 1 位，0–14 | 按位独立，允许重复 |

## 数据

历史开奖数据位于 `data/processed/`，CSV 格式，不含开奖日期列：

- `dlt_draws.csv` — 大乐透（前区 5 + 后区 2）
- `ssq_draws.csv` — 双色球（红球 6 + 蓝球 1）
- `kl8_draws.csv` — 快乐八（开奖 20 码）
- `pl5_draws.csv` — 排列5（d1–d5）
- `qxc_draws.csv` — 七星彩（d1–d6 + special）
