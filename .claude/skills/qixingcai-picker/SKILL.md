# 七星彩选号（五层漏斗 · 按位过滤）

## 项目依赖限制

- **仅允许**读取 `data/processed/qxc_draws.csv`
- **禁止**使用 src/、scripts/、history/、config 等任何其他项目内容

## 原则

- 彩票为随机游戏，历史统计**不能**保证未来结果
- 输出**一注**：前区6位(d1-d6各0-9) + 后区1位(special 0-14)
- 时间戳：北京时间 ISO-8601（`+08:00`）

---

## 架构：五层漏斗（按位独立）

```
选七星彩 Skill 触发
    │
    └─→ Workflow 脚本 (scripts/workflow.js)
           │
           ├─ Phase 1: 数据准备 (haiku) — 按位统计d1-d6+special
           └─ Phase 2: 五层漏斗 (单Agent)
                 ├─ 🔪 杀号   前区每位10→~6, 后区15→~9
                 ├─ 📈 趋势   前区每位~6→~4, 后区~9→~6
                 ├─ 🏗️ 结构   按位奇偶/大小约束
                 ├─ 🔍 形态   跨位模式+后区关联
                 └─ 🎯 精选   最终6+1
```

### 七星彩特点

| 特点 | 说明 |
|------|------|
| 前区按位独立 | d1-d6每位0-9，按各自历史独立分析 |
| 后区独立 | special 0-14，独立于前区分析 |
| 允许重复 | 前区同数字可出现在多个位置 |
| 大小分界 | 前区 0-4小/5-9大，后区 0-7小/8-14大 |
| 无连号约束 | 没有连号/重号硬约束 |
| 跨位形态 | 关注前区重复数字模式、顺子、对称 |

---

## 选号约束

- 前区每位独立筛选，后区独立筛选
- 允许前区数字跨位重复
- 前区奇偶比不过于极端
